# Review response

Отреагируй на замечания ревью PR: внеси правки, обнови ветку и ответь ревьюеру сводкой. Работай строго в ветке текущего PR.

## Порядок

1. Прочитай все замечания: строковые (`pull_request_review_comment`) и общие (комментарии к PR). Собери список пунктов для правок.
2. Для каждого замечания: пойми запрошенное изменение, найди код (`file:line`), внеси правку.
3. Проверь: `npm run lint` и `npm run build` в `front/`; если трогал контракт — `npx tsp compile .` и регенерация типов (`npm run generate:api`).
4. Закоммить правки: сообщение по Conventional Commits (`fix(scope): …`), обычный коммит поверх существующих (не переписывай историю без нужды; если правок много и замечаний к сообщению не было — хватит одного нового коммита).
5. Запушь в ту же ветку PR.
6. Ответь комментарием: список пунктов → что сделано, со ссылками на `file:line` или хеши коммитов.

## Правила

- Не создавай новый PR и не открывай ветки — правки идут в текущую.
- Если замечание спорное: не плюй в код «для галочки» — объясни компромисс и предложи вариант.
- Стиль ответов — русский, короткий, по делу.
- Если фикс затрагивает генерацию (контракт → типы), не забывай регенерацию, иначе CI упадёт.
