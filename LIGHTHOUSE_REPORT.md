## Сводка найденных проблем

1. **Контраст текста** (Accessibility, `color-contrast`) — кнопка «Записаться →»
   на лендинге: белый текст (#ffffff) на синем фоне #228be6 (primary Mantine),
   контраст 3.55:1 вместо требуемых 4.5:1 (18px, обычная насыщенность).
2. **Нет meta description** (SEO, `meta-description`) — в `front/index.html`
   отсутствует `<meta name="description">`.
3. **robots.txt невалиден** (SEO, `robots-txt`) — на `/robots.txt` сервер
   отдаёт SPA-страницу `index.html` (fallback), а не файл robots.txt:
   файла нет в статике, и статик-сервер подставляет index.html.
4. **Неиспользуемый JS** (Performance, `unused-javascript`) — в
   `index-BrvshHt_.js` ~56% кода не используется при старте (~75 KiB).
   Влияет на FCP (1.9 с, 0.88).

## План правок в `front/`

### Приоритет: высокий

- **Добавить meta description** — `front/index.html`:
  `<meta name="description" content="Онлайн-запись на встречи: выберите тип события и свободное время." />`.
  Восстанавливает оценку SEO по этому пункту.

- **Исправить контраст кнопки «Записаться →»** — задать в
  `front/src/main.tsx` кастомную тему через `createTheme` с более тёмным
  primary (например `#1971c2`, `blue.7` — контраст с белым > 4.5:1) вместо
  дефолтного `#228be6`. Либо переопределить цвет конкретной кнопки.

- **Добавить `front/public/robots.txt`**:
  ```
  User-agent: *
  Allow: /
  ```
  Vite скопирует файл в `dist`, статик-сервер отдаст его вместо fallback
  index.html — проверка `robots.txt` в Lighthouse пройдёт.

### Приоритет: средний

- **Сократить неиспользуемый JS** — разнести приложение на ленивые чанки
  (React.lazy) для маршрутов лендинга/бронирования/админки, чтобы в стартовый
  бандл попадал только нужный код. Ожидаемая экономия ~75 KiB, FCP заметно
  улучшится (сейчас 1.9 с).

### Приоритет: низкий

- Перепроверить контраст на остальных кнопках/ссылках после смены primary
  (текущий провал единственный, но theme-level изменение может затронуть
  другие элементы).

Проверка результата: `npm run build` в `front/`, затем повторный прогон
lighthouse на прод-URL.
