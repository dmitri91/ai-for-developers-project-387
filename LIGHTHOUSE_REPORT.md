## Найденные проблемы

### Accessibility (94/100)
- **Низкий контраст кнопки «Записаться →»** — белый текст (#ffffff) на фирменном синем (#228be6) даёт контраст 3.55:1 при требуемых 4.5:1. Элемент: `a.mantine-Button-root` (размер lg) на главной странице.

### SEO (82/100)
- **Нет `meta description`** — страница не задаёт description, Lighthouse не может сформировать сниппет в поисковой выдаче.
- **`/robots.txt` отдаёт HTML** — запрос к `/robots.txt` возвращает `index.html` (SPA-fallback), 14 ошибок синтаксиса. Файл `robots.txt` не существует на сервере.

### Performance (98/100, некритично)
- **Render-blocking CSS** — `index-MgNbK8ar.css` блокирует рендеринг, экономия ~300 ms.
- **Неэффективный кэш статики** — `index-BrvshHt_.js` (~136 KiB) и `index-MgNbK8ar.css` (~39 KiB) не кэшируются на длительный срок; потенциальная экономия ~175 KiB при повторных визитах.
- **Неиспользуемые CSS/JS** — ~35 KiB неиспользуемого CSS и ~75 KiB неиспользуемого JS (следует проверить, не прилетает ли лишнего из Mantine).

## Правки для команды (front/ и деплой)

| # | Правка | Приоритет | Куда |
|---|---|---|---|
| 1 | Добавить `<meta name="description">` в `index.html` | Высокий | `front/index.html` |
| 2 | Устранить низкий контраст кнопки «Записаться»: затемнить фон кнопки (например `#1971c2`) или добавить `color: var(--mantine-color-white)` на тёмный вариант | Высокий | `front/` (тема Mantine) |
| 3 | Добавить `public/robots.txt` в `front/` (SPA отдаёт его как статику) | Средний | `front/public/robots.txt` |
| 4 | Настроить длительный `Cache-Control` для `/assets/*` (имя файла содержит хеш) | Средний | деплой (Render) |
| 5 | Загружать CSS без блокировки рендеринга или минимизировать бандл стилей Mantine | Низкий | `front/` |

Примечание: Best Practices — 100/100, performance-блоки некритичны, спешить с ними не нужно.
