## Сводка найденных проблем

Приложение в хорошем состоянии: Performance и Accessibility выше 90 %, Best Practices — 100 %, CLS равен нулю. Основные потери идут от SEO (82 %) и четырёх точечных проблем производительности и доступности.

### SEO (82 %)

1. **Нет `<meta name="description">`** — страница отдаётся без описания, снижает качество сниппета в поисковой выдаче.
2. **Невалидный `robots.txt`** — запрос `/robots.txt` возвращает HTML главной страницы (SPA-fallback на хостинге), а не сам файл. Lighthouse находит 14 синтаксических ошибок. Краулеры не могут понять правила индексации.

### Accessibility (94 %)

3. **Недостаточный контраст текста кнопки** — белый текст «Записаться →» на фоне `#228be6` (стандартный синий Mantine): контраст 3.55:1 при требуемых 4.5:1 для обычного текста.

### Performance (97 %)

4. **Нет заголовков кэширования** — JS и CSS бандлы (`/assets/index-*.js`, `/assets/index-*.css`) отдаются с `Cache-Control: no-cache` (lifetime 0). Экономия от кэширования — 175 KiB на повторных визитах.
5. **Render-blocking CSS** — главный CSS-файл (≈40 KiB) блокирует первый рендер (~300 мс).
6. **Неиспользуемый CSS** — 89.7 % правил в главном CSS не используются (≈36 KiB). Избыточный CSS — следствие подключения полного набора стилей Mantine.
7. **Неиспользуемый JavaScript** — 55.5 % кода бандла не выполняется при первом рендере (≈77 KiB). SPA грузится единым бандлом без code-splitting по маршрутам.

## Рекомендуемые правки (front/)

Приоритет P0 — делать первыми: дёшево, устраняет целые проваленные проверки.

### P0 — SEO
- [ ] **Добавить `<meta name="description">` в `front/index.html`** (например: «Календарь встреч — запись на встречу онлайн в пару кликов»).
- [ ] **Добавить `front/public/robots.txt`** — Vite автоматически скопирует его в `dist/`. Содержимое минимум:
  ```
  User-agent: *
  Allow: /
  ```
  Убедиться на хостинге, что статический файл отдаётся, а не SPA-fallback.

### P0 — Performance
- [ ] **Включить длительное кэширование статики** — настроить на хостинге (Render) заголовок `Cache-Control: public, max-age=31536000, immutable` для `/assets/*` (имена файлов содержат хеш контента). Повторные визиты станут заметно быстрее.

### P1 — Accessibility
- [ ] **Поднять контраст кнопок «Записаться →»** — использовать более тёмный оттенок primary-цвета Mantine (контраст белого текста ≥ 4.5:1), либо тёмный текст на светлом фоне. Правится в теме приложения (`MantineProvider` / `createTheme`).

### P1 — Performance
- [ ] **Code-splitting по маршрутам** — обернуть страницы (`BookingPage`, `ConfirmBookingPage`, админ-страницы) в `React.lazy` + `Suspense`, чтобы админка и редко используемые экраны не попадали в стартовый бандл (~77 KiB потенциальной экономии).
- [ ] **Убрать лишний CSS Mantine** — подключить только стили используемых компонентов, а не полный `@mantine/core/styles.css` (≈36 KiB экономии). Рассмотреть импорт стилей из конкретных подпакетов.

### P2 — Performance
- [ ] **Снизить влияние render-blocking CSS** — при необходимости вынести критический CSS инлайн или грузить основной CSS асинхронно через `link rel="preload"` + динамическое подключение.
