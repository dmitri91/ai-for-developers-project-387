# Фронтенд «Календарь встреч»

UI-приложение на **React + TypeScript + Vite + Mantine**, работающее с API по контракту (`main.tsp` → `openapi.yaml`).

## Страницы

| URL | Назначение | Эндпоинты контракта |
|---|---|---|
| `/` | Виды встреч (гость): название, описание, длительность | `GET /event-types` |
| `/book/:id` | Выбор свободного слота на 14 дней + бронирование | `GET /event-types/{id}/availability`, `POST /bookings` |
| `/admin` | Типы событий (владелец): список + создание | `GET`/`POST /admin/event-types` |
| `/admin/bookings` | Предстоящие встречи (владелец) | `GET /admin/bookings/upcoming` |

## Быстрый старт

Зависимости и типы уже сгенерированы.

```bash
npm install
npm run generate:api   # перегенерация типов из openapi.yaml (после правок контракта)
```

Запуск в двух терминалах:

```bash
# 1) Бэкенд-заглушка по контракту (Node, без внешних зависимостей), порт 4010
#    Реализует создание типов, доступность слотов, занятость и предстоящие встречи.
npm run mock

# 2) Dev-сервер Vite, порт 5173 (проксирует /event-types, /bookings, /admin на 4010)
npm run dev
```

Открыть http://localhost:5173

## Подключение реального бэкенда

Dev-сервер проксирует запросы к API на `http://localhost:4010` (см. `vite.config.ts`).
Для работы с отдельно запущенным бэкендом укажите его адрес переменной окружения
`VITE_API_BASE_URL` (пример в `.env.example`), либо поменяйте строку `BACKEND` в `vite.config.ts`.
Фронтенд ничего не знает о реализации — только путь и структуру из контракта.
